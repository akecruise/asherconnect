# SALES GUIDE — Quick Answer (โครง — เนื้อหาเต็มตาม Phase 13, 25)

> สำหรับ: sales / senior_sales — ใช้คำตอบได้ทั้งหมดที่ approved, แก้ก่อนส่งได้เสมอ,
> อนุมัติไม่ได้ (approve เฉพาะ admin)

## เปิด Quick Answer
ในช่องพิมพ์ข้อความ → ปุ่ม Quick Answer (หรือพิมพ์ `/` แบบเดิม) — panel จะโชว์:
- **Suggested for this question** — ระบบเดาจากข้อความลูกค้าในแชตนี้ พร้อม % ความมั่นใจ
- หมวดหมู่, ค้นหา, ใช้ล่าสุด, ใช้บ่อย, แนะนำ

## เลือกและส่ง
1. คลิกคำตอบ → ข้อความเติมลงช่องพิมพ์ (ตัวเลขราคา/โปรโมชั่นดึงสดจากระบบ ณ ตอนนั้น)
2. ★ **แก้ก่อนส่งได้และควรทำ** — ปรับชื่อลูกค้า/น้ำเสียงให้เป็นธรรมชาติ
3. กดส่งตามปกติ (ระบบส่งด้วย flow เดิมทุกอย่าง)

## ถ้าคำตอบไม่ตรง
- **Report Incorrect** — เลือกเหตุผล (ไม่ตรง/เก่า/ซ้ำ/อื่น ๆ) + โน้ต → admin เห็นทันที
- **Submit to Knowledge** — คำตอบที่คุณพิมพ์เองแล้วดี ส่งเป็นคำตอบเสนอ → admin ตรวจ

## ถ้ามีตัวแปรว่าง
คำตอบแบบ Dynamic ถ้าข้อมูลจริงยังไม่มี (เช่นยังไม่มีราคาในระบบ) จะเห็นช่องว่างพร้อม
ข้อความแจ้ง — **ห้ามเดาตัวเลขเอง** ให้ใช้ fallback ที่ระบบเตรียมหรือตอบว่าจะตรวจสอบให้

## ความเข้าใจผิดที่พบบ่อย
- Quick Reply ปุ่มเดิมยังอยู่ครบ ใช้สลับกันได้ — ของใหม่ชื่อ "Quick Answer"
- คำตอบที่เห็น = ผ่านการอนุมัติแล้วเท่านั้น ถ้าอยากให้เพิ่มคำตอบ ใช้ Submit to Knowledge
