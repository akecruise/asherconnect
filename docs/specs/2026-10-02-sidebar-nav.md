## 1. เป้าหมาย

1. เปลี่ยนแถบเมนูบน (`#app-nav`) เป็น **sidebar ซ้าย** ที่มีปุ่ม **"ซ่อนเมนู"** ด้านล่าง กดแล้วยุบเหลือไอคอนอย่างเดียว และ **จำสถานะไว้** ข้ามการรีเฟรช/ข้ามหน้า
2. วางโครงเมนูเต็มแบบ LINE OA Manager ที่แมปเข้ากับโมดูลของ Connect
3. ใช้ sidebar ตัวเดียวกันทุกหน้า (`/`, `/stats`, `/logs`, `/quick-replies`) — ตอนนี้หน้าอื่นไม่มีเมนูเลย มีแค่ลิงก์ "กลับ"

## 2. นอกขอบเขต (ห้ามทำในใบงานนี้)

- หน้า **รายชื่อติดต่อ** และหน้า **ส่งข้อความถึงผู้ใช้หลายคน** — ใบงานนี้ทำแค่รายการเมนู (ปิดไว้ ดูข้อ 4) ตัวหน้าอยู่ใบงานอื่น
- ไม่แตะ `connect_private.api`, ไม่เพิ่ม SQL
- ไม่เปลี่ยนสิทธิ์ใคร — ใช้เงื่อนไข role ที่มีอยู่แล้วทุกจุด
- ไม่ออกแบบหน้าแชทใหม่ (คอลัมน์รายการ/แชท/lead card คงเดิม แค่ขยับตามความกว้าง sidebar)

### 4.1 ตั้งค่าแชท (เมนูย่อย)

| เมนูย่อย | ทำอะไร | ใครเห็น |
|---|---|---|
| **ตั้งค่าพื้นฐาน** | เปิดแผงที่ `body.settings-open` เปิดอยู่ตอนนี้ (สถานะช่องทาง, โหมดส่ง, บอท) — **ย้ายตำแหน่งเปิด ไม่สร้างของใหม่** | ทุกคน (สวิตช์ข้างในซ่อนตาม role เดิม) |
| **จัดการแท็ก** | เรียก `openTagAdmin()` เดิม — บนหน้าอื่นที่ไม่ใช่ `/` ให้ไป `/?manage=tags` แล้วเปิด dialog ให้เอง | manager/admin |
| **ข้อความตอบกลับ** | ลิงก์ `/quick-replies` | admin (ตรงกับด่านใน `server.mjs` `quick_reply_*`) |
| **เวลาตอบข้อความ** | dialog เล็กแก้ `sla_minutes` (1–120), `sla_pause_start`, `sla_pause_end` (HH:MM เวลาไทย) ผ่าน `api('setting_list')` / `api('setting_set',{key,value})` เดิม — ห้ามเพิ่ม RPC | manager/admin |

★ เมนูที่ role ไม่มีสิทธิ์ = **ไม่แสดงเลย** (ไม่ใช่ disabled) — ยกเว้นข้อ 2–3 ที่ disabled เพราะ "ยังไม่สร้าง" ไม่ใช่ "ไม่มีสิทธิ์"
★ การซ่อนเมนูเป็นเรื่องหน้าตา ด่านสิทธิ์จริงยังอยู่ที่ฐาน/server ตามเดิม ห้ามย้ายด่านมาไว้ฝั่งหน้าเว็บ

## 5. พฤติกรรม sidebar

### ขนาดตามจอ
| ความกว้างจอ | ค่าเริ่มต้น | ปุ่ม "ซ่อนเมนู" |
|---|---|---|
| ≥ 1024px | กาง 240px (ไอคอน + ตัวหนังสือ) | มี · ยุบเหลือ 64px ไอคอนอย่างเดียว |
| 768–1023px | ยุบ 64px | มี · กางแล้ว **ซ้อนทับ** เนื้อหา (ไม่ดันคอลัมน์) ปิดเมื่อคลิกนอก/Esc |
| < 768px | ซ่อน · ปุ่ม ☰ ที่แถบบนเปิดเป็น drawer ซ้ายเต็มความสูง + ฉากหลังมืด (`--scrim`) | ไม่มี (drawer ปิดด้วย ×, คลิกฉากหลัง, Esc หรือเลือกเมนู) |

### จำสถานะ
- คีย์ `localStorage`: `connect.nav.collapsed` = `"1"` | `"0"` — ใช้ร่วมทุกหน้า
- อ่าน/เขียนใน `try/catch` ทุกครั้ง (โหมดส่วนตัว/ถูกบล็อกต้องไม่พัง — ใช้ค่าเริ่มต้นตามจอแทน)
- จำเฉพาะจอ ≥ 1024 · จอ 768–1023 เริ่มยุบเสมอ · มือถือไม่จำ
- **ห้ามกะพริบตอนโหลด**: ตั้ง class `nav-collapsed` บน `<html>` ก่อนวาดหน้า — เพราะ CSP ห้าม inline ให้ใส่ใน `public/app-nav.js` ที่โหลดแบบ classic `<script src>` (ไม่ defer/ไม่ module) ใน `<head>` ก่อน stylesheet อื่น

### ยุบแล้ว (64px)
- เหลือไอคอน · ตัวหนังสือซ่อน · `title` + `aria-label` ของแต่ละเมนูยังอยู่ (hover เห็นชื่อ)
- badge ยังโชว์ที่มุมไอคอน
- กลุ่ม "ตั้งค่าแชท": กดไอคอนแล้วเมนูย่อยเปิดเป็น flyout ข้างขวา (ไม่กางลงด้านล่าง)

### การเข้าถึง
- `<nav aria-label="เมนูหลัก">` · เมนูที่อยู่หน้าปัจจุบันมี `aria-current="page"`
- ปุ่มซ่อนเมนูมี `aria-expanded` (true = กางอยู่) และ `aria-controls` ชี้ที่ nav
- กลุ่มตั้งค่าแชทเป็น `<button aria-expanded>` ควบคุมรายการย่อย
- ใช้คีย์บอร์ดได้ครบ (Tab/Enter/Space/Esc) · focus ring ใช้ `--focus`
- ขนาดเป้ากด ≥ 44×44 บนมือถือ
