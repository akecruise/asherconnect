## ด้วยมือ (local แล้วซ้ำบน production ด้วยแชต is_test=true เท่านั้น)

### เมนู /media-library
- [ ] เมนู "คลังรูป" โผล่ในแถบซ้ายสำหรับ sales/marketing/manager/admin · reviewer (test_only) ไม่เห็น
- [ ] sales: เพิ่มรูป → ขึ้น "ส่งแล้ว — รออนุมัติ" และยังไม่อยู่ในคลัง
- [ ] marketing: แท็บ "ทั้งหมด" เห็นรูปรออนุมัติ → กดรูป → อนุมัติ → ขึ้นคลัง
- [ ] อัปโหลด WEBP → ได้ JPEG ในคลัง · PNG ใหญ่ ~8 MB → ถูกย่อขอบยาว 2048
- [ ] ตั้งวันหมดอายุเมื่อวาน → หายจากคลังปกติ แต่เห็นในแท็บ "ทั้งหมด" พร้อมป้าย "หมดอายุ"
- [ ] นำออกจากคลัง → หายทั้งสองแท็บ · quick reply ที่ผูกรูปนั้นยังใช้ได้

### ช่องตอบ
- [ ] ปุ่ม "🖼 คลังรูป" เปิด popover แท็บคลังรูป · ปุ่ม "💬 คำตอบด่วน" เปิดแท็บคำตอบ · สลับแท็บแล้ว popover ไม่ปิดเอง
- [ ] พิมพ์ `/` ในช่องว่าง → เปิดแท็บคำตอบสำเร็จรูป
- [ ] Esc ตอนโฟกัสอยู่ใน popover = ปิด · Esc ที่อื่นไม่ปิดอะไร
- [ ] ตัวกรองโครงการเริ่มต้นตามโครงการของเคส
- [ ] แตะ 3 รูป → เลข 1-2-3 ตามลำดับแตะ · แตะซ้ำ = เอาออก · เกินลิมิต (LINE+ข้อความ 4, IG 1) → แจ้งเตือน
- [ ] "แนบในช่องตอบ" → ถาดแนบมีเลขลำดับ · ลบทีละรูปได้ · ผสมกับไฟล์แนบเองได้
- [ ] เลือก quick reply ชุดรูป Naii (`NAII_PHOTO_*`) → ข้อความ + รูปลงถาด ไม่ auto-send
- [ ] ส่ง → LINE ได้รูปตามลำดับแล้วตามด้วยข้อความ · Messenger เหมือนกัน
- [ ] เปิดเคสเดิมซ้ำ → รูปที่ส่งแล้วมีป้าย "ส่งแล้ว" · use_count เพิ่ม
- [ ] รูปในประวัติแชตแสดงผ่าน `/media/` ตามปกติ
- [ ] ส่งรูปล้วน (ไม่มีข้อความ) → นับเป็นการตอบใน SLA/reply stats (`last_agent_reply_at` ขยับ)
- [ ] รูปบางใบส่งไม่ผ่าน (เช่น provider ปฏิเสธ) → สถานะใต้ข้อความแสดง error ไม่เงียบ
- [ ] reviewer login: เปิดแชตทดสอบ → popover คลังรูปเปิดได้ ไม่มี 403/404 ใน console · ไม่มีปุ่มเพิ่มรูป
