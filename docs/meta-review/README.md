# Meta App Review Package — APLUS Connect

APLUS Connect is an internal customer support and sales inbox used by authorized
staff to manage Facebook Messenger conversations sent to our business Facebook Page.

## Permission being reviewed

Business Asset User Profile Access

Used together with:

- pages_messaging

## Review package

| File | Purpose |
|---|---|
| use-case.md | Text for the permission use-case description |
| reviewer-instructions.md | Step-by-step instructions for the Meta reviewer |
| screencast-script.md | Script for the review demonstration video |
| meta-dashboard-checklist.md | Meta Dashboard settings to verify |
| pre-submit-checklist.md | Final checklist before submission |

## Reviewer safety

The reviewer account is a test-only account.

It must only access conversations marked as test data and must never have access
to real customer conversations.

Reviewer credentials must never be committed to this repository.
