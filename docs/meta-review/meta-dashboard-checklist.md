# Meta Dashboard Checklist

Complete these checks before submitting App Review.

## Basic app information

- App name is correct
- App icon is configured
- Business information is correct
- Contact email is monitored
- App domains are correct

## URLs

Verify these URLs are publicly accessible:

- https://inbox.apluscondo.com
- https://inbox.apluscondo.com/privacy
- https://inbox.apluscondo.com/privacy#data-deletion

Privacy Policy must not contain placeholder text.

Data Deletion Instructions must clearly explain how a user can request deletion.

## Facebook / Messenger

- Correct Facebook Page is connected
- Webhook callback URL is correct
- Webhook verification succeeds
- Required Messenger webhook subscriptions are enabled
- pages_messaging configuration is correct

## Permission review

Permission:

Business Asset User Profile Access

The use-case description must explain:

- what profile information is used
- why staff need it
- where it appears in APLUS Connect
- that it is related to customer support/sales conversations

## Reviewer account

- Reviewer login works
- Account is marked test-only
- Test conversations exist
- Reviewer cannot view production customer conversations

## Screencast

The video must show:

1. Messenger test message
2. Message appearing in APLUS Connect
3. User display name/profile identity
4. Reply from APLUS Connect
5. Reply appearing in Messenger

Do not expose tokens, passwords, secrets, or real customer data.
