# Testing Instructions for Meta Reviewer

Thank you for reviewing APLUS Connect.

The test takes approximately 3 minutes.

## Credentials

The App Review form will provide:

- APLUS Connect reviewer login
- Facebook test/tester account access where required

Credentials are supplied through the Meta App Review form and are not stored
in this repository.

## Test steps

1. Open:
   https://inbox.apluscondo.com

2. Sign in using the supplied reviewer account.

3. Open the Facebook Messenger test account or test Page conversation provided
   for App Review.

4. Send a new Messenger message to our business Facebook Page.

   Example:
   Hello, this is a Meta App Review test message.

5. Return to APLUS Connect.

6. Open the Inbox.

7. The new Messenger test conversation should appear.

8. Open the conversation.

9. Verify that the Messenger user's display name is shown with the conversation.

10. Send a reply from APLUS Connect.

11. Return to Messenger and verify that the reply is received.

## Important reviewer isolation

The supplied APLUS Connect reviewer account is a test-only account.

It can access only conversations created for App Review testing and cannot
access our real customer conversations.
